# 🌐 NanoLLM Showcase Web Application

A modern, responsive multi-page portfolio application showcasing the **NanoLLM 4-Week From-Scratch GPT Build**.

---

## 🚀 Features & Pages

* **Home (`/`)**: Hero pitch, key statistics, parameter counts, and unique architectural features.
* **Journey (`/journey`)**: Interactive 26-day timeline with expandable code snippets and "What Broke & The Fix" engineering breakdowns.
* **Architecture (`/architecture`)**: Interactive visual Transformer computational graph with clickable stage tooltips for QKV attention, LayerNorm, and Pre-LN residuals.
* **Results (`/results`)**: Recharts SVG bar chart graphing Perplexity ($76.56 \to 6.64$) and Validation Loss reductions alongside raw benchmark tables.
* **Live Demo (`/demo`)**: Interactive dual-model switcher playground (NanoLLM 211k From-Scratch vs. Fine-Tuned 124M GPT-2) with Temperature, Top-K, and Top-P sliders.
* **About (`/about`)**: Freelance client pitch, technical skill matrix, and GitHub contact links.
* **Theme Switcher**: Instant Day (☀️ Light) & Night (🌙 Dark) theme toggle with full contrast styling.

---

## 🛠️ Stack

* **Framework**: Next.js 14 (App Router)
* **Styling**: Tailwind CSS
* **Visualization**: Recharts
* **Icons**: Lucide React
* **Deployment**: Vercel Serverless
